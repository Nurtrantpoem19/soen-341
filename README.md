# CareerConnect

**Job Search and Application Tracking Platform**

SOEN 341 Software Process — Team Project, Fall 2026

CareerConnect is a planned web application that brings job searching, resume management, recruitment, and application tracking into one place. It serves two primary user groups: **job seekers** and **recruiters**.

**Repository:** [Nurtrantpoem19/soen-341](https://github.com/Nurtrantpoem19/soen-341)

## Project Status

The project is in Sprint 1, focused on requirements, team organization, development setup, and the first basic features. The repository currently contains project documentation only. The features below describe the proposed scope; they are not yet implemented.

## Identified Problem

Job seekers often manage job listings, resumes, deadlines, and application updates across separate websites, documents, and messages. This makes it difficult to track progress, find previous applications, and remember upcoming deadlines. Recruiters also need a clear way to publish opportunities and review candidates throughout the hiring process.

## Proposed Solution

CareerConnect will centralize these activities in a shared platform. Job seekers will be able to maintain a profile, manage resumes, discover opportunities, submit applications, and track their progress through an application dashboard. Recruiters will be able to manage job postings and review applicants. Notifications and saved jobs will help users plan their next steps.

## Proposed Features

### Accounts and Profiles

- User registration and authentication.
- Profile creation and management for job seekers and recruiters.
- Resume upload and management.

### Job Seekers

- Search and filter job opportunities, with proposed filters such as location, industry, experience level, and work arrangement.
- Submit job applications.
- Track application status: **Applied**, **Interview**, **Offered**, or **Rejected**.
- View current and past applications in an application history dashboard.
- Save jobs and manage favourites.
- Receive notifications and reminders for application deadlines, with interview and status alerts proposed as extensions.

### Recruiters

- Create, edit, publish, and archive job postings.
- Review applicant profiles and resumes.
- Track candidates through the hiring process and update application statuses.
